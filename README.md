# K&I Wealth Tech Frontend

A responsive React frontend for discovering, comparing, and checking eligibility for financial opportunities.

## Features

- Requirement-based opportunity discovery
- Amount, tenure, risk preference, and security type inputs
- Client-side form validation
- Dynamic opportunity listing from the supplied CSV dataset
- Search by provider or product
- Risk filtering
- Interest-rate sorting
- Opportunity details popup
- Compare 2–3 opportunities
- Eligibility checking
- Eligible, Conditional, and Not Eligible outcomes
- Eligibility reasons and next actions
- Loading skeleton
- Empty results state
- Error state with retry
- Responsive desktop and mobile layout
- Automated tests using Vitest

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- Vitest
- Testing Library
- Supplied CSV dataset
